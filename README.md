## ✨ Features

- **Satirical Tech Content:** Fake futuristic headlines (Elon Musk's X-OS, Caspian Sea AI servers, GPT-6 asking for a salary).
- **Space-Themed UI:** Deep space background with CSS radial-gradient star effects, dark silver cards (`#1c2026`), and high-contrast typography (`#fffdfa`).
- **Interactive Theme Switcher:** Smooth toggle between Space Mode (with starfield) and Starless Mode, saved via `localStorage`.
- **Font Awesome Integration:** Vector icons for dates, categories, and theme buttons.
- **Responsive Layout:** Responsive grid architecture built using CSS Grid and Flexbox.

---

## 🛠️ Tech Stack

- **Markup:** HTML5 (Semantic tags, BEM class structure)
- **Styling:** CSS3 (CSS Variables, CSS Grid, Flexbox, Transitions)
- **Scripting:** Vanilla JavaScript (ES6+, DOM Manipulation, LocalStorage API)
- **Icons:** Font Awesome 6
